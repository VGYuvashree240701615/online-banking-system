# Online Banking System

This project is a simple Online Banking System developed using HTML, CSS, and JavaScript.

## Features
- User Login
- View Account Balance
- Transfer Money
- View Transaction History

## Tools Used
- Azure DevOps (Boards, Pipeline, Wiki)
- GitHub (Code Hosting)

## CI/CD Pipeline
A CI pipeline was implemented using Azure DevOps to automate the build process and publish artifacts.
